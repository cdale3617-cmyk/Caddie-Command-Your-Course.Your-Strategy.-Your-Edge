# CADDIE COMMAND

Your Course. Your Strategy. Your Edge.

Native Android golf caddie for Samsung Galaxy S24 Ultra and compatible Android devices.

## Core Features
- Intelligent voice caddie
- Worldwide golf course search and mapping
- Live GPS distances
- Weather and wind direction arrows
- Safe yellow route and aggressive red route
- Club selection and shot strategy
- Digital scorecard and round history
- My Bag and club distances
- Shot tracking and golf practice tools
- Green reader provision
- Metres/yards and km/h/mph settings
- Outdoor anti-glare display mode

## Build
Android application built with Gradle and GitHub Actions.
